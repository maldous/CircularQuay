# Circular Quay continuous BAU

The [canonical UIF continuous BAU definition](https://github.com/maldous/uif/blob/develop/docs/operations/business-as-usual.md)
governs eligible Circular Quay work and applies independently of any individual chat or agent session.

**Circular Quay is held.** This reference does not lift the hold, enable dispatch or provider access, change an active claim, or authorize a product deployment. Resume only after explicit authorization through the existing project controls.

Once authorized, qualified Stokowski provider routes may change as evidence and free capacity change; unqualified, unavailable, or paid routes stay closed. Morgan runs in parallel only on distinct eligible issues, with a single fenced owner per issue. Continuous operation is designed to run indefinitely through independent triggers, reconcile and recover from retained evidence, and refill from eligible work without manual dispatch. No paid fallback or inference spending is authorized by this guidance.

For a working branch, fetch and merge this repository's current `develop` before starting. Immediately before committing, fetch again and verify the current tip is an ancestor; merge any advance, preserve local work and rerun affected checks. Do not substitute another base without confirmation.
