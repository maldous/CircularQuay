# Diagram sources

The `.mmd` files describe editable architecture/timeline semantics. The light/dark SVGs are editable, self-contained presentation assets with text alternatives, no scripts, external fonts, or telemetry. They are illustrations, not proof of a security property or a declaration that a feature is qualified.

When changing the design, update both semantic and SVG presentations, verify XML validity and inspect light/dark readability. Keep private environment names, credentials, identifiers and operational endpoints out of public assets.
