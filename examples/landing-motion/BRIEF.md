## Motion thesis

- Focal moment: manual paths settle into one source → local policy → approved app flow, followed by a short denial demonstration. All nodes and meaning exist before JavaScript.
- Continuity: a single timeline moves the diagram, caption and selected chapter together. Direct chapter selection pauses autoplay. Replay is explicit; no endless carousel.
- Feedback: native buttons for chapters, pause/resume and replay; no hover-only or drag-only interaction. Autoplay never updates an ARIA live region.
- Budget: no WebGL, physics, video, external service, runtime library or downloaded logo field. One bounded story, 30fps maximum SVG packet updates, cached path samples, no per-frame layout reads. Stop frame work while hidden/offscreen; reduced motion starts as a static complete route.

## Responsive strategy

Use a horizontal viewBox above 900 CSS px and an independently authored vertical viewBox below it. Tablet landscape and unfolded foldables use the wide route; portrait tablet, folded devices and phones use the vertical route when content requires it. Controls reflow; targets stay at least 44px. `viewport-segment-*` is a progressive enhancement for a reported vertical hinge; use a stacked route to avoid placing the hub across it. No posture, model or user-agent guessing. Screen-reader prose describes the route independently of decorative SVG.
