# CircularQuay landing design brief

## Identity and purpose

Preserve the CircularQuay logo, existing typography, warm ivory/forest palette and consistent light/dark theme. The landing is a focused one-pane introduction to identity, encryption and application delivery, headed **“Get the right secrets ready.”**

## Composition

Use two authentication nodes, two encrypted sources, four environment targets and a central CircularQuay node labeled Managed policies. Six secondary connections represent age, KMS, signing, SCIM, clients and audit. Product names are bold inside each tile, with a concise purpose beneath a prominent mark. The compact landing links directly to the first featured Explore document; an upward wheel or swipe opens the grouped Explore home.

The diagram and story remain continuously animated; the horizontal divider between them is removed. Active and delivered routes, plus node overlays, use 2px emphasis while idle bases remain lighter; the hub base has no border. Text padding is 18px. On phones, node faces use an icon/name/purpose grid with an 18px minimum row gutter. The motto stays on one line at every viewport. Headers use a common stable root gutter and padding; language precedes theme at widths up to 760px so the logo and wordmark remain legible.

The catalogue rotates all 113 local examples: 30 identity providers, 35 encrypted sources and 48 applications, using 108 distinct SVGs. Fair variant bags cover 24 actor roles and 12 contexts. Both source slots may select any encrypted source; no source is forced. Balanced workload masks rotate none, first action, second action and both, with one optional feature in the first scene. Without JavaScript, the complete scene remains available as a static fallback.

The loader fills the viewport, centres the logo, uses a neutral-grey opacity breath, then fades logo out and main content in. It is sized at 50vw with a height cap; reduced motion is still. Escape closes a search dropdown without pausing that flow, while the diagram retains its own Escape pause behavior. The footer is one discreet horizontal line at the viewport bottom; very short or zoomed layouts retain natural scrolling for access.

## Documentation and login

Explore home keeps its six task-oriented paths and 55 documents while reducing repeated labels and horizontal rules. Document summaries use the first real manifest heading. It includes Help distribution and autocomplete; the same compact menu appears on desktop, tablet and foldable landing layouts. Wide tables retain 9rem minimum cells and horizontal scrolling on narrow screens. The local source freeze contains 59 source files and is based on canonical commit `15f368a9f8ac4b45f5d92772c492e863b0a0f5f9`, with manifest SHA-256 `abb8878ee734dbe398f98c15c8abd22de1e3a511e1620d2de9917f4fd0d16b45`. Current guides use `cq` and `cq-sdk`; historical engineering records are identified and retain their revision-specific evidence.

Login uses the same shell and a 30-provider wall followed by account actions and the real footer in one document scroll. Preview feedback appears only after interaction. The public frontend is live at `circularquay.aldous.info` and `cq.aldous.info`; authentication/provisioning, vendor adapters and production legal content remain pending. Detailed validation and design assessment are recorded separately in `CANDIDATE-REVIEW.md`.
